# PM workflow

## Goal

Maintain a traceable plan, decomposition, statuses, risks, and plan/fact.

## Inputs

Team roster, milestones, decisions, YouGile task state, and repository changes.

## Procedure

1. Read the relevant track block in `state.md`.
2. Reconcile task status with YouGile.
3. Add decisions and risks when they appear.
4. Update only affected plan/fact blocks.

## Done

Every active item has an owner, acceptance criterion, next action, and tracker link.
